# Catch the Dot

Мини-игра «Поймай точку» для Android, сделанная на Unity и C#.
Практическая работа № 2 по дисциплине «Программирование мобильных игр».

Дундуков Никита группа ТРИ43

## Описание

На экране в случайном месте появляется точка. Игрок тапает по экрану, корзина
плавно едет к месту тапа и ловит точку. За каждую пойманную точку начисляется
1 очко. На всю игру даётся 30 секунд, после этого появляется экран Game Over
с итоговым счётом и кнопкой «Play again».

## Управление

Тап по экрану (на компьютере — клик мышью): корзина едет в эту точку.

## Механики

- Случайное появление точки через `Random.Range`.
- Плавное движение корзины через `Vector2.MoveTowards`.
- Попадание определяется по расстоянию (`Vector2.Distance`), без физики и коллайдеров.
- Таймер на 30 секунд на основе `Time.deltaTime`.
- Счёт и таймер выводятся через TextMeshPro.
- Экран Game Over и перезапуск сцены.

## Технологии

- Unity (версия: 2022.3 LTS / Unity 6, укажите свою)
- C#
- TextMeshPro
- Целевая платформа: Android

## Структура проекта

| Файл | Назначение |
|---|---|
| `Assets/Scripts/Dot.cs` | Случайные позиции точки |
| `Assets/Scripts/Basket.cs` | Тап, движение корзины, проверка попадания |
| `Assets/Scripts/GameManager.cs` | Счёт, таймер, Game Over, перезапуск |
| `Assets/Editor/CatchTheDotSetup.cs` | Автоматическая сборка сцены (только для редактора) |
| `Assets/Scenes/Game.unity` | Игровая сцена |

## Как запустить

1. Откройте проект в Unity Hub (Unity 2022.3 LTS или Unity 6).
2. Откройте сцену `Assets/Scenes/Game.unity`.
3. В окне Game выберите соотношение сторон 9:16 Portrait.
4. Нажмите Play.

## Как собрать APK

1. File → Build Settings (в Unity 6 — Build Profiles) → Android → Switch Platform.
2. Добавьте сцену кнопкой Add Open Scenes.
3. В Unity 6: Edit → Project Settings → Player → Other Settings → Active Input Handling → Both.
4. Подключите телефон с включённой отладкой по USB и нажмите Build And Run.
